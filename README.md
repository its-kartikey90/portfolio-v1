# Portfolio v1 — Kartikey Dixit

My personal brand site with smooth animations, dark mode, and a blog.

## Features

- 🌗 **Dark/Light mode** — respects system preference
- ✨ **Framer Motion** — smooth page transitions and scroll animations  
- 📝 **Blog** — built-in blog with 3 posts
- 📱 **Responsive** — looks great on every device
- ⚡ **Fast** — Vite + React, 100/100 Lighthouse

## Stack

- React 18 + Vite
- Tailwind CSS
- Framer Motion
- React Router

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
